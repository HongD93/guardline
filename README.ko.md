# Guard Line

한국어 통화의 보이스피싱 위험 신호와 그 근거 문장을 보여주는 브라우저 프로토타입이다.

[English](README.md)

AssemblyAI Voice Agent Hackathon 참가를 위해 제작했다. 합성 음성이나 마이크 입력을 AssemblyAI로 보내 전사하고, 위험 신호와 원문 근거를 표시한다. 위험 등급에서는 시각 경고와 브라우저 음성 경고를 제공한다.

보호자 알림은 시뮬레이션이며 실제 메시지 발송·전화 종료·상대방 신원 확인 기능은 없다. 점수는 규칙 기반 위험 지표이며 사기 확률이 아니다.

## 로컬 실행

Java 21 이상, Node.js 22.12 이상 또는 24, 설정된 Streaming·LLM 모델을 사용할 수 있는 AssemblyAI 계정이 필요하다.

1. `backend/application-local.yaml`을 만들고 다음을 설정한다. 이 파일은 Git과 Docker에서 제외된다.

```yaml
guardline:
  assemblyai:
    api-key: YOUR_ASSEMBLYAI_API_KEY
```

2. `backend`에서 `./gradlew bootRun`을 실행한다. Windows는 `.\gradlew.bat bootRun`을 사용한다.
3. `frontend`에서 `npm ci`, `npm run dev`를 실행한다.
4. `http://localhost:5175`에서 시나리오를 선택하고 재생한다. 마지막 판정 중에는 기다리고 ‘종료됨’ 상태의 결과를 확인한다.

설정 파일 대신 `ASSEMBLYAI_API_KEY` 환경변수를 사용할 수 있다. 프론트엔드에는 키를 넣지 않는다. 시나리오 재생도 실제 API를 사용한다. 마이크 입력은 외부 서비스에 전송되므로 검증에는 포함된 합성 음성을 사용한다.

## 판정 해석

S1 기관 권위, S2 공포·압박, S3 격리·입막음, S4 설치·링크·민감정보 요구, S5 금전 요구를 감지한다. 상의 권유·공식 채널 확인·사용자 발신·안내 종결은 감점 요소다.

기관을 밝히는 정상 통화도 S1·S2가 나올 수 있다. 가족 송금 요청에서 ‘주의’가 나와도 사기로 확정한 것이 아니다. 대화만으로 가족의 신원을 확인할 수 없으므로 송금 전 알고 있던 연락처로 확인하라는 의미다. ‘안전’도 신원이 검증됐다는 뜻은 아니다.

점수 구간은 안전 0–29.9, 주의 30–54.9, 경고 55–79.9, 위험 80–100이다. 확인된 격리 요구의 신뢰도가 0.8 이상이면 최소 80점이 적용된다. 점수와 임계치는 휴리스틱이며 실제 금융사기 탐지 성능으로 검증되지 않았다.

## 처리와 검증

Vue에서 16 kHz 모노 PCM을 Spring WebSocket 릴레이로 보내 AssemblyAI가 전사한다. 확정 전사를 규칙과 LLM Gateway로 분석한다. 개발 설정은 한국어 Streaming `whisper-rt`, LLM `qwen3.5-4b-32k-fast`이며 환경변수로 변경할 수 있다.

LLM 인용은 원문 한 줄과 대조하고 S4·S5는 실제 요청 표현도 확인한다. 감점과 S3는 규칙 확인 결과만 사용한다. 위험 신호는 통화 중 누적하고 감점은 다시 검사한다. 연속 신호 체인은 발생 시각의 인과관계를 증명하지 않는다.

백엔드 `./gradlew test bootJar`, 프론트엔드 `npm run build`로 검증한다. 단위 테스트는 외부 응답을 대체하므로 실연동 성능 증명이 아니다. `tools/eval-detector.mjs`도 모델 원시 응답만 비교하며 제품 판정 파이프라인과 다르다.

포함된 음성 7종은 합성 시연 자료이며 대표성 있는 평가 데이터셋이 아니다. 전사·화자 구분·모델 변동과 우회 표현 때문에 오탐·누락이 가능하다. 엄격한 인용 검증이 정상 탐지를 버릴 수도 있다. 현재 UI와 경고 음성은 한국어다. 브라우저 음성 지원이 없으면 시각 경고를 확인한다.

## 배포

Dockerfile은 양쪽을 빌드해 한 Java 서버에서 화면·음성 파일·WebSocket을 제공한다. 명령과 전체 환경변수는 [영문 실행 안내](README.md#container-and-hosting)를 따른다. 이미지 빌드는 테스트를 생략하므로 사전에 백엔드 테스트를 실행한다. 공개 서비스에는 HTTPS와 정확한 `CORS_ALLOWED_ORIGINS`를 설정한다.

기본 사용량 제한은 하루 시작 50회, 동시 오디오 2개, 통화 180초다. 카운터는 단일 서버 메모리에 있어 재시작 시 초기화되므로 확실한 과금 상한이 아니다. 무료 호스팅이어도 API 사용료는 별도다. 공개 배포와 공급자 계정의 사용량 상한은 아직 검증되지 않았다.

Hong DaeWoon의 개인 프로젝트이며 구현·검증에 AI 코딩 지원을 사용했다. 음성은 `edge-tts`로 생성했고 실제 통화 녹취가 아니다.
